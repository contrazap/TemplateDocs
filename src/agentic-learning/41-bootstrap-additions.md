## Bootstrap additions

- **Calibration** (bootstrap step 4), recorded in `MEMORY.md` → Learning: what the user wants to understand, time per working session, and any familiarity the user states. Start every concept as *new* unless the user says otherwise.
- **Environment inventory** (bootstrap step 5): record which SDKs, tools, templates, services and caches are already installed, and who installed them. Every later install happens inside a step with 📋 Before and 📤 Check output, so the user sees the change.
- **Handoff:** the first plan's overview and its first step file, ready to read. Nothing is implemented before the user's first **go**.
