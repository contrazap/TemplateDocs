## States

Plans: Planned → Pending (overview and first step written; first go pending) → In progress → **Implemented** (all steps verified; plan review pending) → **Verified** (review passed; acceptance has evidence).

Steps: Outlined (overview row only) → 📖 Ready to read (file written) → Executed (agent done; the user's read and check pending) → ✅ Verified (the user's check passed).

Markers: `🎯` target · `🧭` concepts · `📋` before · `🔧` do · `⚖️` decisions · `🔍` read the code · `📤` check, review, needs you · `📝` record · `✅`/`⬜` progress.
