## Learning support

`MEMORY.md` → Learning holds the profile, the concept list and the skill record.

- **Concept list:** each concept with its familiarity: *new* (introduced), *met* (the user has read and checked a step that uses it), *familiar* (the user has used it in later steps without needing the explanation). Update it at each step's record.
- **Detail graduates per skill:** the first time, every command, flag and line is explained; after one clean repetition, steps, expected results and the changed lines; after two, goal, acceptance and what is new. The skill record lists each skill, how often it was done and its current detail. Acceptance and checks never shrink with the detail.
- **Typing it yourself** (optional): when a step is a core workflow that later steps repeat and takes ≤ ~30 minutes, the agent offers that the user does it from the step text; the agent then reviews it. Never offered for mechanical or bulk work. Declining needs no reason.
- **Optional interactions**, never required: predict-then-observe (the user predicts a check's result before running it), explain-back, debug drills.
- **Pace:** size steps so a working session covers a few complete steps, including reading and checks.
