## Bootstrap additions

- **Calibration** (bootstrap step 4) records in the `AGENTS.md` user profile what the user already knows, so explanations stay short there (steps stay complete regardless), and what is new, so it is explained at first use. It also records the time budget: sessions per week, their usual length and the days they fall on.
- **Coverage map** (see *Arcs, coverage and time*): list the track's topic clusters, mark the ones the user practised before this workspace, tag each `core` or `later` by its value to the user's goal, and list the out-of-scope topics once with where the user learns them instead. Size the core to the time budget and state the period it is expected to take.
- **Roadmap:** the time section, the first arc with its plans as one-line outcomes, the later core arcs as one-line themes, and the coverage map. Only the first plan is written in detail.
- Verification (bootstrap step 5) exists so plans carry only user actions: check the installed tools and versions and the starter or template content the first plan uses, and note what the later arcs will need that is not yet checked.
- Handoff: report the entry point, the current plan, the next action and the core's time estimate.
