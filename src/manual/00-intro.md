# Manual implementation workspace template

A self-contained template for agent-managed workspaces in which **the user implements the work** while the agent plans, coaches, reviews and maintains the records.

Other templates in the family: `AGENTIC_LEARNING_WORKSPACE_TEMPLATE.md` (the agent implements step by step while the user builds along and learns), `AUTONOMOUS_AGENTIC_WORKSPACE_TEMPLATE.md` (agents build end to end; the user approves at milestone gates) and `ITERATIVE_HYBRID_WORKSPACE_TEMPLATE.md` (human-first with agent acceleration; the direction evolves and plans are written just in time).

## How to use this template

Provide this file to the agent (from the canonical repository or a local copy), together with the add-ons the project uses (see *Optional add-ons*), and supply the requirements separately. For example:

> Read MANUAL_IMPLEMENTATION_WORKSPACE_TEMPLATE.md and use it to generate or adapt this workspace's documentation and AGENTS.md. Use the requirements I provide separately. Preserve existing work and create only the first detailed plan for each active project. This request is for documentation, not implementation.

The example invocation does not need to be stored in generated documentation.
